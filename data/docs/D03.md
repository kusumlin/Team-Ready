Query access to the Lumen data warehouse is separate from Analytics Workspace access.
Request it in the Access Portal under Data Warehouse, Analyst role.
Analyst role access needs manager approval and a completed Handling Customer PII training.
Tables tagged pii are masked by default for the Analyst role.
For help writing your first queries, ask in #data-help or contact the Data Platform team.
