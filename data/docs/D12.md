Clone the monorepo with git clone git@git.lumen.dev:lumen/monorepo.git.
Install the toolchain by running make bootstrap from the repository root.
Start the local stack with make dev, which runs the API, the web app and a local database.
If make bootstrap fails, delete the .cache folder and run it again.
Ask in #platform-help if your setup is still blocked after one hour.
