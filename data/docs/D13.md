Staging deploys happen automatically when a pull request is merged to main.
To deploy a branch manually, run lumen deploy --env staging from the repository root.
Manual staging deploys need a green CI build.
Check deploy status in the #deploys Slack channel.
You do not need special access to deploy to staging.
