    How it stays honest

    A model drafts each answer as claims with quotes. Plain code then keeps a claim only if all of these hold:

    1. It cites a doc that was actually retrieved for your question.
    2. Its quote appears word for word in that doc.
    3. The quote isn't cut out of a sentence that says "not".
    4. Most of the claim's words appear in the quote.
    5. Every number in the claim is in the quote.
    6. If nothing survives, TeamReady asks a person instead of guessing.
