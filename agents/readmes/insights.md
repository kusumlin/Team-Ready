# TeamReady Insights: the Friction Map for People Ops

![tag:innovationlab](https://img.shields.io/badge/innovationlab-3D8BD3)
![tag:hackathon](https://img.shields.io/badge/hackathon-5F43F1)

Turns repeated new-hire blockers into anonymous, fixable patterns. Events hold only a topic, the docs read first and whether the blocker was resolved. No names, no message text, and groups under 5 events are hidden.

- **Free:** say "friction map" for the top clusters.
- **Paid (0.1 FET via the Payment Protocol):** say "full report" for the patterns behind each cluster and an AI-drafted fix to the doc causing the biggest gap. The doc owner approves the fix before anything changes.

Business model: companies pay per insights report; the employee-facing assistant stays free.
